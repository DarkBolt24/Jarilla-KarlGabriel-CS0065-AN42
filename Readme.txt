CS054 Laboratory Activity 5: GA - Sentiment AnalysisAuthors: Karl Gabriel R. Jarilla, Lorenzo Gabriel ElazeguiSection: AN42Course: CS054 (Intelligent Systems)OverviewThis project contains Python programs demonstrating basic Natural Language Processing (NLP) techniques to determine the mood and feelings expressed in textual data. The activity is divided into two main parts: a library-based approach and a custom rule-based approach.   Activity ComponentsPart 1: TextBlob Sentiment Analysis (Section VI)
A script that utilizes the TextBlob library's simple API to perform basic NLP tasks. It prompts the user for 10 distinct sentences, evaluates the polarity (ranging from -1 to 1) of each sentence, and categorizes them as Negative (p < 0), Neutral (p = 0), or Positive (p > 0). It concludes by outputting a statistical summary of the analyzed sentences.   Part 2: Tone Analysis Challenge (Section VII)
A custom sentiment analysis program that calculates the happiness and sadness levels of a user-inputted sentence without relying on external NLP libraries. It uses two functions—number_happy(sentence) and number_sad(sentence)—to count the occurrence of words against predefined datasets of happy and sad words. The overall tone is determined by comparing which word count is higher.   PrerequisitesTo run the scripts, ensure you have Python installed along with the required textblob library.You can install the required library using pip:Bashpip install textblob
How to RunExecute the Part 1 script to test the TextBlob polarity evaluation. Enter 10 sentences when prompted to see the live sentiment classification and final summary.Execute the Part 2 script to test the custom tone analyzer. Enter a single sentence to see the breakdown of happy vs. sad words and the resulting tone classification.
